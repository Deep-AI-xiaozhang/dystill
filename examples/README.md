# 示例产物（来自真实产物，已脱敏并截断）

这个目录不是手写 demo，而是从仓库在本机跑出的真实记录里截取的片段。
所有内容都经过脱敏和截断；没有为了「看起来完整」而补写任何笔记内容。

## 文件与来源

| 文件 | 真实来源 | 做了什么 |
|---|---|---|
| `note.md` | `data/aweme_<id-A>/note.md`（源文件 103 行） | 把 `key` 换成 `aweme:7000000000000000000`；开头加脱敏说明；保留前三节，略去第四节「总结与适用场景」并在末尾标注截断 |
| `check.md` | `data/aweme_<id-B>/check.md`（源文件 97 条声明、1750 行） | 保留报告顺序的前 40 条明细（3 条 ❌ + 12 条 ⚠️ + 25 条 ✅）；汇总表按这 40 条重算；`key` 替换；作者昵称/仓库 owner 替换；加脱敏说明与截断说明 |
| `check.json` | `data/aweme_<id-B>/check.json`（源文件 97 条声明） | 保留与 `check.md` 相同的 40 个 `cid`；`counts` 按这 40 条重算；`key` 替换；作者昵称/仓库 owner 替换；开头新增 `example_notice`，末尾新增 `example` 字段记录原总数与截断事实 |

> 两个真实 aweme id 已在示例正文和本文档中隐去（占位为 `<id-A>` / `<id-B>`）；
> 维护者的本地来源记录保留完整映射，不随仓库发布。

> **注意**：`note.md` 与 `check.md/check.json` 来自**两个不同的视频**。
> `note.md` 是笔记示例，`check.*` 是核对报告格式示例，两者不是同一条记录，不能互相对照或拼接。

## 脱敏清单

| 类型 | 处理 |
|---|---|
| 真实 aweme id | 全部替换为 `aweme:7000000000000000000`（不在示例中保留原值） |
| 作者昵称 / 仓库 owner | 全部替换为 `某作者` / `example-owner`（不在示例中保留原值） |
| 抖音短链 / 本地绝对路径 | 示例中不包含（`meta.json` 未复制） |
| 上传者身份 | 源笔记 frontmatter 本身没有作者字段；`source: douyin` 保留，仅表示来源平台 |

脱敏后的自检结果（在 `examples/` 下逐个文件 grep）：

- 真实 aweme id（两种原值）：0 次
- 作者昵称 / 仓库 owner（四种原值）：0 次

## 怎么读这些示例

- `note.md`：最终产物形态。顶部 YAML 是身份/类型/日期；正文按「结论先行 → 视频内容 → 知识要点」组织。
- `check.md`：人读报告。❌/⚠️ 排在最前，✅ 在后；每条带原片时间戳与证据原文；末尾列出「主动跳过的句子」。
- `check.json`：机器读报告。`claims[]` 每条含 `cid / text / verdict / reason / evidence[]`；`counts` 是汇总。

## 这不是「可复现基准」

`check.*` 只截取了一条真实记录的前 40 条声明，用于展示**报告格式**。
它不是基准集，不能用来计算准确率，也不是可复跑的验收数据。
验收口径、历史数字与不可复现说明见 [`../docs/BENCHMARK.md`](../docs/BENCHMARK.md)。
